# ecTools

The goal of ecTools is to provide tools for ecosystem accounting and
assessments.

## eaTools = ecTools

The package was renames ecTools in may 2026.

## Installation

You can install the development version of ecTools from
[GitHub](https://github.com/) with:

``` r

# install.packages("devtools")
devtools::install_github("NINAnor/ecTools")
```
